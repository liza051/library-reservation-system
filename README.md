Library Reservation System
About the Project

Library Reservation System is an information system designed to manage book reservations in a library.

The project focuses on designing a conceptual data model that describes the main entities, their attributes, relationships, and cardinalities.

Project Purpose

The purpose of this project is to create an Entity-Relationship (ER) model for a library reservation system.

The model describes how readers interact with the library catalog, reserve books, and borrow physical book copies.

Main Features
Reader management
Book catalog management
Author and category management
Physical book copy management
Book reservations
Book loans and returns
Project Scope

This project focuses on conceptual data modeling and requirements analysis.

It does not include physical database implementation, SQL scripts, or application development.

Modeling Approach

The ER model will be created using Mermaid ER Diagram syntax.

The model will be reviewed against the requirements to ensure correct relationships, cardinalities, and normalization.
